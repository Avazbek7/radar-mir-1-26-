# radar-mir-1-26-
# Ультразвуковой радар на Arduino

Мини-проект по курсу «Введение в робототехнику и ИИ», КГТУ им. И. Раззакова, кафедра АИИиР.
Группа МиР(б)-1-26, модуль 1.

## Идея

Сервопривод поворачивает ультразвуковой датчик HC-SR04 от 0° до 180°, Arduino измеряет расстояние на каждом угле
и передаёт данные по UART на компьютер, где строится карта препятствий в виде экрана радара.
Если объект ближе 20 см, срабатывают зуммер и красный светодиод.

## Что используем из курса

- HC-SR04 и защита от показания −1 (Пр3);
- сервопривод и ШИМ (Лб2);
- `loop()` без `delay()` на `millis()` (лекция 5);
- передача данных по UART (лекция 5);
- фильтр скользящего среднего для шумных замеров (Пр2).

## План

1. Модель в Wokwi: серво + HC-SR04, вывод «угол, расстояние» в монитор порта.
2. Визуализация радара на ПК (Python + matplotlib или Processing).
3. Сборка на реальном железе, тест на 3 расстояниях.
4. Отчёт: схема, код, фото, видео работы.
